# AI-Driven Job Search Application Workflow

The new structured application pipeline is unavailable until Slices 2–4 pass.
Inherited `/apply` materials may be read as design references, but do not
pretend the new database-backed workflow exists.

Required final behavior:

- select approved claims and project components before drafting;
- show requirement coverage and genuine gaps;
- never create or strengthen unsupported claims;
- separate drafting from fresh-context review;
- compile and validate PDF/ATS output;
- require user approval before submission;
- never submit automatically.
